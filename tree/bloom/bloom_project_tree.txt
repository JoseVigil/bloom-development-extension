# `.gen/` fue reemplazado por `.ing/` (ver ING_Intent_Spec_v1_0.md, "Rationale
# del cambio de estrategia: gen/ → ing/"). Única rama modificada respecto al
# original: `.intents/.gen/` → `.intents/.ing/`, más el renombre del archivo
# de instrucciones del bot en `.project/`. `.dev/` y `.doc/` quedan idénticos,
# sin cambios.

# NOTA — fuera de alcance de este árbol: `gen.json`, `.history/.delta_N/`, y
# `.cache/.semantic-index.json` (ver ING_Intent_Spec_v1_0.md §7) viven a nivel
# Nucleus, no a nivel de este proyecto — su árbol real está en
# `bloom_nucleus_tree.txt`, que no forma parte de esta sesión. No se inventa
# su ubicación acá.

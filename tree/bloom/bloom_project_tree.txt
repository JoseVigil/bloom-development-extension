# bloom_project_tree.txt
# Reemplaza a bloom_project_tree_gen.txt — renombrado porque el tipo de intent
# `.gen/` fue reemplazado por `.ing/` (ver docs/intents/ING_Intent_Spec_v1_1.md,
# "Rationale del cambio de estrategia: gen/ → ing/").
#
# v3 (esta revisión): incorpora la rama `.intents/.dis/` — séptimo tipo de intent,
# `dis/` (Discovery), que corre después de una o más corridas de `ing/` para la
# reestructuración retrospectiva y global de la topología de Dominios (fusión,
# split, rename, altas de arista cross-domain). No es una fase del workflow de
# Mandate Génesis (Fases 1-4): es un servicio aparte, invocado bajo demanda o
# tras acumulación de cambios incrementales. Ver:
#   - docs/intents/ING_Intent_Spec_v1_1.md (reemplaza a ING_Intent_Spec_v1_0.md
#     referenciada en versiones previas de este árbol — v1.1 saca el campo
#     `domain` de `gen.json`, ver su Changelog v1.0 → v1.1)
#   - docs/intents/DIS_Intent_Spec_v1_0.md (nueva, spec del intent `dis/`)
#   - BLOOM_Mandate_Genesis_Roadmap_Maestro_v3.md §8 (pedido de esta actualización)
#
# Único otro cambio de esta revisión: se agrega `.ai_bot.dis.intent.bl` en
# `.project/`, por simetría con `.ai_bot.{dev,doc,ing}.intent.bl` — inferencia
# editorial, ningún spec de intent toca `.project/` explícitamente; revisar si
# no corresponde. `.dev/`, `.ing/` y `.doc/` quedan idénticos a la revisión
# anterior, sin cambios de forma.
#
# NOTA — fuera de alcance de este árbol: `gen.json`, `.history/.delta_N/`, y
# `.cache/.semantic-index.json` (ver docs/intents/ING_Intent_Spec_v1_1.md §7,
# docs/intents/DIS_Intent_Spec_v1_0.md §7.2) viven a nivel Nucleus, no a nivel
# de este proyecto — su árbol real está en `bloom_nucleus_tree.txt`, que no
# forma parte de esta sesión. No se inventa su ubicación acá. Esto incluye a
# `dis/`: aunque `.ratification/` es quien en última instancia aplica cambios
# sobre `.cache/.semantic-index.json`, ese archivo en sí sigue siendo Nucleus-
# level — lo que este árbol sí documenta son sus copias/deltas *locales* al
# intent (`.domain_graph_snapshot.json`, `.domain_graph_delta.json`).
